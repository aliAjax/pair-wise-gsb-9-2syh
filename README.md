# 文献初筛台

在原"研究文献库"基础上扩展的文献初筛工具：纯前端、无后端、不增加依赖，数据保存在浏览器 localStorage。

## 分层组织

- `src/lib/` 条目资料、判定规则、本地保存（与页面完全分开的纯逻辑层）
  - `dedupe.js`　DOI/标题/年份归一化，同篇判定，来源与别名保留合并
  - `importer.js`　数据库导出（CSV/TSV/JSON）解析，中英文表头模糊映射
  - `model.js`　条目与批次数据结构
  - `rules.js`　两人初筛、争议、导师裁决、修订留痕的全部判定规则
  - `storage.js`　localStorage 读写、旧版研究库一次性迁移、演示数据
  - `util.js`　通用工具
- `src/ui/` 页面组件（`App` / `DeskPage` / `BatchesPage` / `ItemList` / `ItemDetail` / `ImportModal`）
- `scripts/test-logic.mjs` 纯逻辑自测，`npm test`

## 规则要点

1. **去重合并**：导入批次按 DOI 判同；DOI 缺失时按"标题 + 年份"判同。每个数据库来源都挂在条目上；对不上的标题、网页链接、来源 DOI 作为别名保留，字段只补不覆盖。
2. **两人初筛**：两名审阅者各自填纳入/排除和理由（必填）。两人都提交后初判冻结；意见相反自动进入**争议区**。
3. **导师裁决**：争议条目在导师裁决前不会进入全文阶段；裁决后结论锁定。
4. **修订留痕**：已确认条目不直接改判，只能追加一条修订说明；所有初判、裁决、修订按时间线保留可查，当前结论以最新修订为准。
5. **批次留档**：每次导入生成批次记录，批次页可看各批去重后条目数与审筛进度。

## 使用

```bash
npm install
npm run dev      # 本地开发
npm test         # 逻辑自测
npm run build    # 构建到 dist/
```

首次打开自动从旧版 `research-library` localStorage 迁移；无旧数据时使用演示数据（含一致纳入、争议、待审三种状态）。侧栏可导出 JSON 备份与纳入条目的引用列表。
